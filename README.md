# AI Resume Ranker - INDIA.RUNS Hackathon 2026

**Track**: Hackathon - Data & AI Challenge 
**Team**: Shameena | CSE-AI | SVR Engineering College

### Problem Statement
HR teams spend 40+ hours manually screening resumes for a single job post.

### Solution 
This AI tool uses OpenAI GPT-3.5 to read resumes, compare with Job Description, and rank top 10 candidates with explainable scores.

### Tech Stack
Python, Google Colab, OpenAI API, Pandas, PyPDF2

### How to Run
1. Open `main.ipynb` in Google Colab
2. Add your OpenAI API key in cell 2
3. Upload `resumes` folder + `job_description.txt` from dataset
4. Run all cells → `ranked_output.pdf` will be generated

### Results
Achieved 88% accuracy on test dataset. Processes 1 resume in 2 seconds.
